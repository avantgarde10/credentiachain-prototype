# Financial model (Python)

Educational project for the course Introduction to Finance. Not a real product, service or investment offer.

`model.py` calculates the three-year plan of CredentiaChain: revenue, costs, 20% corporate income tax with losses carried forward,
free cash flow, break-even, NPV, payback, IRR, terminal value, the pessimistic scenarios and the investor return.
All figures are in KZT million and are invented for the course. Run: `python3 model.py` (writes `model2.json`).
